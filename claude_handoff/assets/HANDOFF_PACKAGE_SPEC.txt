Claude Handoff Package Spec for Wendy Wu QBR Streamlit Exports

Purpose
The Streamlit app should output a zip that an operator can upload directly to Claude/Codex to produce a final presentation matching the Google Slides reference deck.

Required zip files
1. report.txt
   Raw report text generated by the app. This is the source of truth.

2. original_streamlit_prompt.txt
   The prompt used by the app. Rename prompt.txt to original_streamlit_prompt.txt in the handoff zip.

3. {{client_slug}}_streamlit_output.pptx
   The Streamlit-generated PPTX. This is only a secondary source for coverage/intent, not the visual target.

4. reference_deck_exported_from_google_slides.pptx
   PowerPoint export of the Q1 reference deck. Include it when the app has access to it as a static asset/configured file/upload.

5. README_FOR_CLAUDE.txt
   Generated from README_FOR_CLAUDE_TEMPLATE.txt.

6. CLAUDE_PROMPT.txt
   Generated from CLAUDE_PROMPT_TEMPLATE.txt.

7. SLIDE_MAPPING.csv
   Generated from SLIDE_MAPPING_WWT_QBR_TEMPLATE.csv with dynamic fields filled in.

8. SOURCE_SECTION_INDEX.txt
   Generated by parsing report.txt.

9. QA_CHECKLIST.txt
   Generated from QA_CHECKLIST_TEMPLATE.txt.

10. CHART_QA_ADDENDUM_FOR_CLAUDE.txt
   Static file included verbatim.

11. PACKAGE_MANIFEST.json
   Machine-readable manifest for debugging and audit.

Dynamic variables
- client_display_name: e.g. "Wendy Wu Tours UK" or "Wendy Wu Tours Australia"
- client_slug: e.g. "wendy_wu_uk" or "wendy_wu_australia"
- report_family: "Wendy Wu QBR"
- period_label: e.g. "Q2 2026 (Apr - Jun 2026)"
- quarter_short: e.g. "Q2 2026"
- reference_deck_url: the Google Slides reference deck URL
- streamlit_pptx_filename: final filename inside zip
- has_reference_pptx: true/false
- headline_sales_leads
- headline_cost
- headline_cpl
- headline_cvr

Headline KPI extraction
Read the "Overall Quarter Summary" section. In "Key Metrics + YoY", extract:
- Sales Leads
- Cost
- CPL
- CVR
Use the displayed values exactly, including currency symbols and separators.

Reference deck
Current reference deck URL:
https://docs.google.com/presentation/d/1ctx-YpaHfYTJ-sJgWW_BGUTtbeLiEU7xF2JX76CkNkw/edit?slide=id.p35#slide=id.p35

The reference deck is the visual target. The Streamlit PPTX is not the visual target.

Chart QA
Every handoff package must include CHART_QA_ADDENDUM_FOR_CLAUDE.txt and the generated prompt/checklist must reference it. This is required because prior outputs matched content but had squashed/clipped charts.

Packaging constraints
- Do not hardcode a quarter, market, or KPI values.
- Do not include local absolute paths in generated Claude-facing files.
- Keep file names stable.
- Keep all text files UTF-8.
- Preserve the existing Streamlit report and PPTX downloads; add the handoff package as an additional export.
