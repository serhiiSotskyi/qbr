Claude Handoff Package Spec for Olympic Holidays Streamlit Exports

Purpose
The Streamlit app should output a zip that an operator can upload directly to Claude/Codex to produce a final Olympic Holidays presentation matching the Google Slides reference deck.

Required zip files
1. report.txt
   Raw report text generated by the app. This is the source of truth.

2. original_streamlit_prompt.txt
   The prompt used by the app. Rename prompt.txt to original_streamlit_prompt.txt in the handoff zip.

3. olympic_holidays_streamlit_output.pptx
   The Streamlit-generated PPTX. This is only a secondary source for coverage/intent, not the visual target.

4. reference_deck_exported_from_google_slides.pptx
   PowerPoint export of the Olympic Holidays Google Slides reference deck. Include it when the app has access to it as a static asset/configured file/upload.

5. README_FOR_CLAUDE.txt
   Generated from README_FOR_CLAUDE_TEMPLATE.txt.

6. CLAUDE_PROMPT.txt
   Generated from CLAUDE_PROMPT_TEMPLATE.txt.

7. SLIDE_MAPPING.csv
   Generated from SLIDE_MAPPING_OLYMPIC_HOLIDAYS_QBR_TEMPLATE.csv with dynamic fields filled in.

8. SOURCE_SECTION_INDEX.txt
   Generated by parsing report.txt.

9. REFERENCE_DECK_OUTLINE.txt
   Generated from REFERENCE_DECK_OUTLINE_TEMPLATE.txt.

10. INPUT_FILES_MANIFEST.txt
   Generated from INPUT_FILES_MANIFEST_TEMPLATE.txt with uploaded source filename metadata.

11. QA_CHECKLIST.txt
   Generated from QA_CHECKLIST_TEMPLATE.txt.

12. CHART_QA_ADDENDUM_FOR_CLAUDE.txt
   Static file included verbatim.

13. PACKAGE_MANIFEST.json
   Machine-readable manifest for debugging and audit.

14. source_data/
   Standardized copies of the raw CSV uploads.

Dynamic variables
- client_display_name: "Olympic Holidays"
- report_family: "Olympic Holidays PPC QBR"
- period_label: e.g. "Q1 2026 (Jan - Mar 2026)"
- quarter_short: e.g. "Q1 2026"
- period_months_label: e.g. "January - March 2026"
- reference_deck_url
- streamlit_pptx_filename: "olympic_holidays_streamlit_output.pptx"
- has_reference_pptx: true/false
- headline_revenue
- headline_purchases
- headline_cpa
- headline_cost
- headline_aov
- headline_cost_per_atc
- headline_total_atc
- trend_brand_display_name
- trend_category_display_name

Headline KPI extraction
Read the "Executive Summary" section first. Extract these values exactly when present:
- Revenue
- Purchases
- CPA
- Cost
- AOV
- Cost/ATC
Read the "ATC Analysis" section for:
- Total ATC
- Cost per ATC
If the report uses alternative labels, preserve the displayed report label and value in PACKAGE_MANIFEST.json warnings.

Reference deck
Current reference deck URL:
https://docs.google.com/presentation/d/1kIfuKkkU2KNTjaPetIJDqZ-iHHss8NXMbhobLiVD9H4/edit?slide=id.p5#slide=id.p5

The reference deck is the visual target. The Streamlit PPTX is not the visual target.

Reference slide count
11 slides.

Chart QA
Every handoff package must include CHART_QA_ADDENDUM_FOR_CLAUDE.txt and the generated prompt/checklist must reference it.

Packaging constraints
- Do not hardcode the current quarter or KPI values.
- Do not include local absolute paths in generated Claude-facing files.
- Keep file names stable.
- Keep all text files UTF-8.
- Preserve the existing Streamlit report and PPTX downloads; add the handoff package as an additional export.
- Keep the Olympic Holidays handoff mapped to 11 slides unless the source deck/template changes.
