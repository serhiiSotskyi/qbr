Input files and roles

Primary generated files
- report.txt: Source of truth for final deck content.
- {{streamlit_pptx_filename}}: Streamlit-generated structure/content aid only.
- original_streamlit_prompt.txt: Background only.
- reference_deck_exported_from_google_slides.pptx: Visual template bridge if included.

Raw source data files
- source_data/performance.csv
  Original upload: {{performance_original_filename}}
  Role: Performance source. Columns usually include Date/Month, Channel or Campaign Type, Revenue, Purchases, Cost, CPA, AOV, ATC, Cost/ATC, Impressions, Clicks, CTR, CPC.

- source_data/auction_insights.csv
  Original upload: {{auction_original_filename}}
  Role: Auction Insights source.

- source_data/google_trends_olympic_holidays.csv
  Original upload: {{brand_trend_original_filename}}
  Display term: {{trend_brand_display_name}}

- source_data/google_trends_category.csv
  Original upload: {{category_trend_original_filename}}
  Display term: {{trend_category_display_name}}

- source_data/plan_or_forecast.csv
  Original upload: {{plan_original_filename}}
  Role: Optional plan/forecast source. Include only if the Olympic Holidays pipeline accepts one. Use only as audit/context unless plan comparisons are explicitly in report.txt.

- source_data/{{additional_standardized_filename}}
  Original upload: {{additional_original_filename}}
  Role: Additional source accepted by the Olympic Holidays pipeline. Record every additional upload in PACKAGE_MANIFEST.json.

Priority rule
report.txt is primary. Raw CSVs are secondary and should not override report.txt values unless report.txt lacks enough detail to render a chart and the CSV clearly provides the exact underlying source.
