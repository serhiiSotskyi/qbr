SOURCE_SECTION_INDEX.txt generation rules for Olympic Holidays

Input
- report.txt generated by the Streamlit app.

Output
- A plain text index that lists each report section in order with line numbers.

Parsing rules
1. Split report.txt into lines.
2. Treat lines matching "[Section Name]" as section starts.
3. Also treat prominent unbracketed headings matching expected slide names as section starts when bracketed headings are absent.
4. Number every section in source order.
5. Record the 1-based line number where each section title starts.
6. Extract period_label from the first line matching a quarter/date pattern such as "Q1 2026 (Jan - Mar 2026)".
7. Extract quarter_short from the first "Qn YYYY" match.
8. Extract period_months_label from a line such as "January - March 2026" when present.
9. Extract slide number from the "Slide: N" line following each section when present.
10. Do not fail if a future report has extra sections; include them.
11. If expected sections are missing, write a "Missing expected sections" note in SOURCE_SECTION_INDEX.txt and PACKAGE_MANIFEST.json.

Expected current Olympic Holidays sections
01. Cover
02. Olympic Holidays Trends
03. Holidays to Greece Trends or Category Trends
04. Executive Summary
05. Auction Insights
06. Overall Performance
07. YoY Matched-Month Comparison
08. End of Period
09. Channel Performance
10. Generic Performance
11. ATC Analysis

Important checks
- If Generic Performance is absent, record the substituted source section in PACKAGE_MANIFEST.json.
- If ATC Analysis is absent, record the missing section and leave slide 11 as a clear human-review placeholder.
- Google Trends section display names should come from CSV headers, not from report section names when report section names are export filenames.
- Do not add Testing, Next Steps, or Other Updates as expected sections for Olympic Holidays unless the app/source explicitly emits them.
