Auction Insights - Red Funnel Quarter Rules

Goal
Build a quarter-only Red Funnel competitive landscape slide for the quarter being reported, with same-quarter YoY comparison when the prior-year Red Funnel Auction Insights export is supplied.

Slide behavior
Use one Red Funnel slide. Do not create both a Red Funnel quarter slide and a separate Red Funnel YoY slide.

Required source
Use a quarter-only Auction Insights export for the report quarter.
For Q2 2026 this means Apr 1, 2026 through Jun 30, 2026.

Use source_data/auction_insights_red_funnel_prior_year_quarter.csv for the same quarter prior year when it is supplied.
For Q2 2026 this means Apr 1, 2025 through Jun 30, 2025.

If the uploaded auction insights file contains more than the report quarter, filter it to the quarter before generating the Red Funnel section.

Required competitor
The slide should focus on Red Funnel. If the source uses a different exact domain/name, detect likely Red Funnel rows by normalized text matching, for example:
- redfunnel.co.uk
- Red Funnel
- red funnel

Metrics to include where available
- Impression Share
- Overlap Rate
- Position Above Rate
- Top of Page Rate
- Absolute Top of Page Rate
- Outranking Share

Comparison behavior
- Show Red Funnel only.
- If previous-period metrics are supplied, show prior quarter, current quarter, pp change, and a concise "what it means" note for each metric.
- If only current-quarter metrics are supplied, show current-quarter values and explain what they mean. Clearly mark the YoY comparison as unavailable.

Slide title
Use:
- Competitive Landscape - Red Funnel YoY

Generated report section
Add:
[Auction Insights - Red Funnel Quarter]

- Use the same table styling as the reference competitive landscape slide.
- Include a concise headline box above the table.
- Include bullets below the table.
- Do not invent metrics that are absent from the source.
