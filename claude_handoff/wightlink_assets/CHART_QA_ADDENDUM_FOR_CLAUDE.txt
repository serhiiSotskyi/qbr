Chart QA Addendum for Wightlink Decks

Problem to prevent
Deck content can be correct while chart images are too tightly rendered or incorrectly scaled inside the template slots. This causes labels, value annotations, legends, and axis text to look squashed, clipped, or overlapping.

Reference standard
Use the Wightlink 2025/26 Year Report reference deck as the visual standard for chart scale, spacing, margins, label size, border treatment, and composition. Generated Q2 charts should feel like the reference charts were updated with new data, not like newly designed charts.

Slides to inspect
- Google Trends chart slides: 4, 5, 6
- All Performance YoY Trend: 13
- Brand Performance YoY Trend: 15
- Generics Performance YoY Trend: 17
- PMax Performance YoY Trend: 19
- Any performance summary slide where a chart is added: 12, 14, 16, 18

Chart rendering rules
- Preserve the chart slot size and position from the reference deck.
- Do not stretch chart images non-proportionally.
- Use fit/contain placement, not crop/fill placement.
- Export chart images at high resolution, ideally 2x or 3x the displayed slide size.
- Leave internal padding inside every exported chart image so labels cannot be cut off after insertion.
- Add at least 10-15% internal padding around chart labels; use 20-25% right padding for charts with end labels.
- Use font sizes that match the reference chart appearance after insertion.
- Avoid chart titles inside the image when the slide already has a title, unless the reference chart image includes a title in that same position.
- Keep legends readable but compact.
- For dual-axis or multi-line charts, do not let labels or legends cover the plotted lines.
- Keep color coding consistent across performance trend slides.

Required visual QA
For every chart slide, create or inspect a full-slide screenshot/thumbnail after chart replacement. The pass is not complete until each chart passes these checks:
- No number is clipped.
- No label overlaps another label, legend, line, bar, point, or axis.
- No chart appears squeezed vertically or horizontally.
- The chart is centered in its intended slot.
- The chart has comparable whitespace to the reference.
- The chart does not collide with bullets, table text, headers, footers, or logos.
- The slide still matches the reference deck layout.

Second-pass instruction
If a chart cannot be made readable within the existing slot, prioritize legibility while preserving the template:
1. reduce nonessential chart text,
2. abbreviate category labels,
3. move or simplify legends,
4. increase chart image padding,
5. reduce marker/annotation density,
6. only then slightly resize the chart within the existing visual bounds.

Final response
List the slides whose charts were changed and confirm that screenshots/thumbnails were checked after the fix.
