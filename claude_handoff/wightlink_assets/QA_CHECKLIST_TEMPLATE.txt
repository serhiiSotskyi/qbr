Required QA before delivery

V2 packages
If QA_CHECKLIST_V2_ADDENDUM.txt is included, run it in addition to this checklist.

Deck identity
- Final deck is a copy of the Google Slides reference deck or a PPTX built from reference_deck_exported_from_google_slides.pptx.
- Final deck follows the Wightlink reference deck structure.
- Final deck is editable after Google Slides import, not one image per slide.
- Client naming is Wightlink.
- Period is {{period_label}}.

Stale content
- No old period labels remain unless clearly part of a comparison that report.txt provides.
- No old KPI values remain.
- No old Red Funnel YoY, ad creative, testing, next steps, or other updates content remains unless report.txt provides it.
- No wrong-client copy remains.

Data integrity
- All KPI values match report.txt exactly.
- All YoY values match report.txt exactly.
- All tables match report.txt exactly, including symbols, percentages, dashes, and row order.
- Auction Insights tables match report.txt.
- Google Trends slides are correctly titled using source_data CSV headers.
- Every report.txt section is represented somewhere in the deck.

Manual placeholders
- Missing Red Funnel/ad creative slide is a clear placeholder.
- Missing Testing slides are clearly marked for human completion.
- Missing Next Steps slide is clearly marked for human completion.
- Missing Other Updates slide is clearly marked for human completion.

Visual fidelity
- Typography, Wightlink colors, dark navy sections, footer treatment, KPI cards, and table styling match the reference deck.
- Text does not overflow or wrap awkwardly in title/footer bands.
- Tables fit within slide bounds and remain readable.
- Chart/image slots are replaced with current-period visuals and no stale chart images remain.
- Every chart slide has been checked against CHART_QA_ADDENDUM_FOR_CLAUDE.txt.
- No chart labels, value annotations, legends, or axis labels are clipped or overlapping.
- Chart images are placed with fit/contain behavior and are not stretched non-proportionally.
- No objects overlap unintentionally.

Final response
- If the output is native Google Slides, return the new Google Slides URL only.
- If the output is PPTX, return the finished PPTX and state it is ready to import into Google Slides.
- Include a short note listing manual placeholders that remain.
- Do not return the original reference deck URL as if it were the output.
