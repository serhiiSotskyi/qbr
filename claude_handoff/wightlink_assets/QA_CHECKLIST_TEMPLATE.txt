Required QA before delivery

Deck identity
- Final deck is a copy of the Wightlink Google Slides reference deck or a PPTX built from reference_deck_exported_from_google_slides.pptx.
- Final deck is suitable for Google Slides import.
- Final deck follows the Wightlink reference visual system, not a generic design style.
- Final deck keeps the 27-slide reference structure unless the user explicitly approves a shorter QBR deck.

Stale content
- No unsupported old-period current content remains.
- No old month labels remain unless part of a prior-period comparison.
- No unsupported creative analysis, testing, next-step, or other-update content remains.

Data integrity
- Headline KPI values match report.txt exactly.
- All KPI cards, YoY values, tables, and bullets pulled from report.txt match exactly unless a source inconsistency is documented.
- Trend slide titles use human-readable query names from CSV headers, not raw filenames.
- Auction insight table values match report.txt/raw_inputs exactly.
- Plan-book values are not used to override report.txt KPIs.

Manual placeholders
- Unsupported Testing slides are clearly marked for account-team completion.
- Unsupported Next Steps are clearly marked for account-team completion or labelled as draft recommendations for review.
- Unsupported Other Updates are clearly marked for account-team completion.
- Top Performing Campaigns slide is a placeholder unless campaign-level source data exists.

Visual fidelity
- Typography, colors, footer style, KPI block styling, tables, dividers, and chart frames match the Wightlink reference deck.
- Text does not overflow or wrap awkwardly in title/footer bands.
- Tables fit within slide bounds and remain readable.
- Every chart slide has been checked against CHART_QA_ADDENDUM_FOR_CLAUDE.txt.
- No chart labels, value annotations, legends, or axis labels are clipped or overlapping.
- Chart images are placed with fit/contain behavior and are not stretched non-proportionally.
- No objects overlap unintentionally.

Final response
- If the output is native Google Slides, return the new Google Slides URL only.
- If the output is PPTX, return the finished PPTX and state it is ready to import into Google Slides.
- Include a short note listing manual placeholders that remain.
- Do not return the original reference deck URL as if it were the output.
