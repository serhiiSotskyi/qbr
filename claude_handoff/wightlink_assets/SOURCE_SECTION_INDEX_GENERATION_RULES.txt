SOURCE_SECTION_INDEX.txt generation rules for Wightlink

Input
- report.txt generated by the Streamlit app.

Output
- A plain text index that lists each bracketed report section in order with line numbers.

Parsing rules
1. Split report.txt into lines.
2. Treat lines matching [Section Name] as section starts.
3. Number every section in source order.
4. Record the 1-based line number where each section title starts.
5. Extract period_label from the first line matching a quarter/date pattern such as "Q2 2026 (Apr - Jun 2026)".
6. Extract slide number from the "Slide: N" line following each section when present.
7. Do not fail if a future report has extra sections; include them.
8. If expected sections are missing, write a "Missing expected sections" note in SOURCE_SECTION_INDEX.txt and PACKAGE_MANIFEST.json.

V2 period metadata
- Extract ytd_period_label when present.
- Extract previous_ytd_period_label when present.
- Record current and previous YTD trend source filenames for all three trend terms when present.
- Record plan source URL or plan CSV filename when present.

Important checks
- Do not treat removed Plan vs Actual detail slides as missing.
- If the Red Funnel prior-year auction source is absent, record a warning that YoY change values may be unavailable.
- Google Trends section display names should come from CSV headers, not from report section names when report section names are export filenames.
- For V2, do not treat missing YTD trend pairs or missing quarter-only Red Funnel source as successful; record a warning and produce a clear placeholder only if the user allows package generation to continue.
