Claude Handoff Package Spec for Wightlink Streamlit Exports

V2 update
For the July 2026 Wightlink QBR update, this package also includes V2 requirements:
- YTD Google Trends comparison charts.
- Quarter-only Red Funnel Auction Insights.
- Additional YTD slides for Brand, Generics, and PMax.
- Plan comparison lines on KPI cards.

The V2 implementation should include these additional files in the generated handoff package:
- UPDATED_SLIDE_MAPPING_WIGHTLINK_QBR_V2_TEMPLATE.csv or an equivalent generated SLIDE_MAPPING.csv
- QA_CHECKLIST_V2_ADDENDUM.txt
- GOOGLE_TRENDS_YTD_COMPARISON_RULES.txt
- PLAN_COMPARISON_RULES.txt
- AUCTION_INSIGHTS_REDFUNNEL_QUARTER_RULES.txt
- YTD_MONTHLY_BREAKDOWN_RULES.txt

Purpose
The Streamlit app should output a zip that an operator can upload directly to Claude/Codex to produce a final Wightlink presentation matching the Google Slides reference deck.

Required zip files
1. report.txt
   Raw report text generated by the app. This is the source of truth.

2. original_streamlit_prompt.txt
   The prompt used by the app. Rename prompt.txt to original_streamlit_prompt.txt in the handoff zip.

3. wightlink_streamlit_output.pptx
   The Streamlit-generated PPTX. This is only a secondary source for coverage/intent, not the visual target.

4. reference_deck_exported_from_google_slides.pptx
   PowerPoint export of the Wightlink reference deck. Include it when the app has access to it as a static asset/configured file/upload.

5. README_FOR_CLAUDE.txt
   Generated from README_FOR_CLAUDE_TEMPLATE.txt.

6. CLAUDE_PROMPT.txt
   Generated from CLAUDE_PROMPT_TEMPLATE.txt.

7. SLIDE_MAPPING.csv
   Generated from SLIDE_MAPPING_WIGHTLINK_QBR_TEMPLATE.csv with dynamic fields filled in.

8. SOURCE_SECTION_INDEX.txt
   Generated by parsing report.txt.

9. REFERENCE_DECK_OUTLINE.txt
   Generated from REFERENCE_DECK_OUTLINE_TEMPLATE.txt.

10. INPUT_FILES_MANIFEST.txt
   Generated from INPUT_FILES_MANIFEST_TEMPLATE.txt with uploaded source filename metadata.

11. QA_CHECKLIST.txt
   Generated from QA_CHECKLIST_TEMPLATE.txt.

12. CHART_QA_ADDENDUM_FOR_CLAUDE.txt
   Static file included verbatim.

13. PACKAGE_MANIFEST.json
   Machine-readable manifest for debugging and audit.

14. source_data/
   Standardized copies of the raw CSV uploads.

Dynamic variables
- client_display_name: "Wightlink"
- report_family: "Wightlink PPC QBR"
- period_label: e.g. "Q2 2026 (Apr - Jun 2026)"
- quarter_short: e.g. "Q2 2026"
- ytd_period_label: e.g. "YTD 2026 (Jan - Jun 2026)"
- previous_ytd_period_label: e.g. "YTD 2025 (Jan - Jun 2025)"
- reference_deck_url
- streamlit_pptx_filename: "wightlink_streamlit_output.pptx"
- has_reference_pptx: true/false
- headline_purchases
- headline_cost
- headline_purchase_revenue
- headline_cpa
- headline_roas
- headline_aov
- trend_1_display_name
- trend_2_display_name
- trend_3_display_name
- trend_1_current_ytd_file
- trend_1_previous_ytd_file
- trend_2_current_ytd_file
- trend_2_previous_ytd_file
- trend_3_current_ytd_file
- trend_3_previous_ytd_file
- has_plan_source: true/false
- plan_source_url

Headline KPI extraction
Read the "All Performance Summary" section. In "KPI Cards", extract:
- Cost
- Purchases
- Purchase Revenue
- CPA
- ROAS
- AOV
Use the displayed values exactly, including currency symbols and separators.

Reference deck
Current reference deck URL:
https://docs.google.com/presentation/d/1QBixtNRD_N_qZ6J56RyfM1vvrTudrZUowZIMdBoGhso/edit?slide=id.p1#slide=id.p1

The reference deck is the visual target. The Streamlit PPTX is not the visual target.

V2 target slide count
The reference deck has 27 slides. The V2 output target has 31 slides after adding:
- Red Funnel Quarter.
- Brand Monthly Breakdown YTD.
- Generics Monthly Breakdown YTD.
- PMax Performance Summary YTD.

Chart QA
Every handoff package must include CHART_QA_ADDENDUM_FOR_CLAUDE.txt and the generated prompt/checklist must reference it.

Packaging constraints
- Do not hardcode the current quarter or KPI values.
- Do not include local absolute paths in generated Claude-facing files.
- Keep file names stable.
- Keep all text files UTF-8.
- Preserve the existing Streamlit report and PPTX downloads; add the handoff package as an additional export.
