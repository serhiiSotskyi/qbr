Wightlink Claude Handoff Package Spec

Purpose
The Streamlit app should output a zip that an operator can upload directly to Claude/Codex to turn a Wightlink QBR output into a final Google Slides-style deck matching the Wightlink reference template.

Required zip files
1. report.txt
   Raw report text generated by the app. Primary source of truth.

2. original_streamlit_prompt.txt
   The prompt used by the app. Rename prompt.txt to original_streamlit_prompt.txt in the handoff zip.

3. wightlink_streamlit_output.pptx
   Streamlit-generated PPTX. Secondary source for coverage/intent, not the visual target.

4. reference_deck_exported_from_google_slides.pptx
   PowerPoint export of the Wightlink 2025/26 Year Report reference deck.

5. README_FOR_CLAUDE.txt
   Generated from templates/README_FOR_CLAUDE_TEMPLATE.txt.

6. CLAUDE_PROMPT.txt
   Generated from templates/CLAUDE_PROMPT_TEMPLATE.txt.

7. SLIDE_MAPPING.csv
   Generated from templates/SLIDE_MAPPING_WIGHTLINK_QBR_TEMPLATE.csv with dynamic fields filled in.

8. SOURCE_SECTION_INDEX.txt
   Generated by parsing report.txt.

9. RAW_INPUTS_MANIFEST.txt
   Generated from templates/RAW_INPUTS_MANIFEST_TEMPLATE.txt and actual uploaded files.

10. REFERENCE_DECK_OUTLINE.txt
   Static or generated outline of the 27-slide Wightlink reference deck.

11. QA_CHECKLIST.txt
   Generated from templates/QA_CHECKLIST_TEMPLATE.txt.

12. CHART_QA_ADDENDUM_FOR_CLAUDE.txt
   Static file included verbatim.

13. PACKAGE_MANIFEST.json
   Machine-readable manifest for debugging and audit.

14. raw_inputs/
   Stable-name copies of the uploaded source CSVs.

Dynamic variables
- client_display_name: "Wightlink"
- period_label: e.g. "Q2 2026 (Apr - Jun 2026)"
- quarter_short: e.g. "Q2 2026"
- reference_deck_url: Wightlink reference Google Slides URL
- reference_slide_count: 27
- streamlit_slide_count: parsed from generated PPTX/report
- headline_cost
- headline_purchases
- headline_purchase_revenue
- headline_cpa
- headline_roas
- headline_aov
- trend_queries: list extracted from Google Trends CSV headers

Headline KPI extraction
Read the "All Performance Summary" section. Extract the KPI Cards:
- Cost
- Purchases
- Purchase Revenue
- CPA
- ROAS
- AOV
Use displayed values exactly, including currency symbols and separators.

Reference deck
Current reference deck URL:
https://docs.google.com/presentation/d/1QBixtNRD_N_qZ6J56RyfM1vvrTudrZUowZIMdBoGhso

The reference deck is the visual target. The Streamlit PPTX is not the visual target.

Chart QA
Every handoff package must include CHART_QA_ADDENDUM_FOR_CLAUDE.txt and the generated prompt/checklist must reference it.

Packaging constraints
- Do not include local absolute paths in generated Claude-facing files.
- Keep file names stable.
- Keep all text files UTF-8.
- Preserve the existing Streamlit report and PPTX downloads; add the handoff package as an additional export.
